# 📝 React Notes App

A simple and responsive **Notes Application** built using **React.js** and **Tailwind CSS**.

This project allows users to create notes by entering a heading and details. Newly created notes are displayed dynamically in the **Recent Notes** section.

## 🚀 Features

- Create notes with a heading and details
- Display newly created notes dynamically
- Responsive layout
- Sticky-note style UI
- Clean and simple interface
- Built with React Hooks
- Styled using Tailwind CSS
- Uses Flexbox for arranging note cards

## 🛠️ Technologies Used

- React.js
- Tailwind CSS
- JavaScript
- HTML
- Vite
